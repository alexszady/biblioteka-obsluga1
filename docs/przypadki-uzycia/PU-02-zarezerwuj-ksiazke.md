# PU-02 – Zarezerwuj książkę

## Nazwa

Zarezerwuj książkę

## Aktor główny

Czytelnik

## Cel

Umożliwienie czytelnikowi zarezerwowania wybranej książki.

## Warunki wstępne

- Czytelnik ma dostęp do systemu.
- Książka znajduje się w katalogu.
- Czytelnik posiada konto.
- Książka może zostać zarezerwowana.

## Warunki końcowe

Rezerwacja książki zostaje zapisana w systemie.

## Przebieg podstawowy

1. Czytelnik wyszukuje książkę.
2. System wyświetla informacje o książce.
3. Czytelnik wybiera opcję „Zarezerwuj książkę”.
4. System sprawdza możliwość rezerwacji.
5. System zapisuje rezerwację.
6. System wyświetla potwierdzenie rezerwacji.

## Przypadek alternatywny

### A1 – Rezerwacja niemożliwa

1. System sprawdza możliwość wykonania rezerwacji.
2. System stwierdza, że rezerwacja nie jest możliwa.
3. System wyświetla odpowiedni komunikat.

## Rezultat

Rezerwacja książki zostaje zapisana w systemie.
