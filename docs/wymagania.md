# Wymagania systemu

## Wymagania funkcjonalne

### WF-01 – Wyświetlanie zawodników

System musi umożliwiać wyświetlenie listy zawodników drużyny.

### WF-02 – Dodawanie zawodnika

System musi umożliwiać dodanie nowego zawodnika.

Podczas dodawania należy podać:

- imię i nazwisko,
- numer,
- pozycję,
- liczbę goli,
- liczbę asyst,
- liczbę występów.

### WF-03 – Edycja zawodnika

System musi umożliwiać zmianę danych zawodnika.

### WF-04 – Usuwanie zawodnika

System musi umożliwiać usunięcie zawodnika.

### WF-05 – Statystyki

System musi przechowywać i wyświetlać:

- liczbę występów,
- liczbę goli,
- liczbę asyst.

### WF-06 – Terminarz

System musi umożliwiać wyświetlenie listy meczów.

Dla meczu system przechowuje:

- przeciwnika,
- datę,
- godzinę,
- miejsce,
- wynik.

### WF-07 – Zarządzanie meczami

System umożliwia:

- dodawanie meczu,
- edycję meczu,
- usuwanie meczu.

### WF-08 – Tabela strzelców

System musi umożliwiać wyświetlenie zawodników uporządkowanych
według liczby zdobytych goli.

## Wymagania niefunkcjonalne

### WNF-01 – Responsywność

Interfejs powinien być czytelny na różnych rozdzielczościach ekranu.

### WNF-02 – Przechowywanie danych

Dane powinny być przechowywane w bazie danych.

### WNF-03 – Czytelność

Interfejs powinien umożliwiać łatwe przeglądanie informacji.

### WNF-04 – Obsługa błędów

System powinien informować użytkownika o niepoprawnych danych.
