# PU-07 – Wyświetl tabelę strzelców

## Aktor główny

Użytkownik

## Cel

Wyświetlenie tabeli strzelców drużyny.

## Warunki wstępne

- System jest uruchomiony.
- Baza danych jest dostępna.
- W systemie znajdują się zawodnicy.

## Warunki końcowe

System wyświetla tabelę strzelców.

## Przebieg zdarzeń

1. Użytkownik otwiera aplikację.
2. Użytkownik przechodzi do tabeli strzelców.
3. System pobiera dane zawodników.
4. System sortuje zawodników według liczby goli.
5. System tworzy tabelę.
6. System wyświetla tabelę.
7. Użytkownik przegląda ranking.

## Informacje w tabeli

- miejsce,
- zawodnik,
- liczba zdobytych goli.

## Rezultat

Użytkownik otrzymuje tabelę strzelców.
