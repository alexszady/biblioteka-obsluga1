# PU-05 – Zarządzaj katalogiem

## Nazwa

Zarządzaj katalogiem

## Aktor główny

Bibliotekarz

## Cel

Umożliwienie bibliotekarzowi zarządzania informacjami
o książkach znajdujących się w katalogu.

## Warunki wstępne

- Bibliotekarz ma dostęp do systemu.
- Bibliotekarz posiada odpowiednie uprawnienia.

## Warunki końcowe

Informacje w katalogu zostają dodane, zmienione lub usunięte.

## Możliwe operacje

- dodanie książki,
- edycja informacji o książce,
- usunięcie książki,
- dodanie egzemplarza,
- aktualizacja lokalizacji,
- aktualizacja dostępności.

## Przebieg podstawowy

1. Bibliotekarz otwiera moduł zarządzania katalogiem.
2. Bibliotekarz wybiera operację.
3. Bibliotekarz wprowadza lub zmienia dane.
4. System waliduje dane.
5. System zapisuje zmiany.
6. System wyświetla potwierdzenie.

## Przypadek alternatywny

### A1 – Nieprawidłowe dane

1. System wykrywa nieprawidłowe dane.
2. System wyświetla komunikat.
3. Bibliotekarz poprawia dane.

## Rezultat

Katalog biblioteki zawiera zaktualizowane informacje.
