# PU-06 – Wyświetl terminarz

## Aktor główny

Użytkownik

## Cel

Wyświetlenie terminarza meczów drużyny.

## Warunki wstępne

- System jest uruchomiony.
- Baza danych jest dostępna.

## Warunki końcowe

System wyświetla terminarz.

## Przebieg zdarzeń

1. Użytkownik otwiera aplikację.
2. Użytkownik przechodzi do terminarza.
3. System pobiera mecze z bazy danych.
4. System sortuje mecze według daty.
5. System wyświetla terminarz.
6. Użytkownik przegląda mecze.

## Informacje o meczu

- przeciwnik,
- data,
- godzina,
- miejsce,
- wynik.

## Przypadek alternatywny

### A1 – Brak meczów

1. System sprawdza bazę danych.
2. System nie znajduje meczów.
3. System wyświetla informację o braku spotkań.

## Rezultat

Użytkownik otrzymuje terminarz drużyny.
